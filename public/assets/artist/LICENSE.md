# Artist photography — license tracking

Any image stored in this folder must have a row below listing:

- **file** — exact filename.
- **photographer** — credited name.
- **rights holder** — entity holding the license (usually Universal Music Canada or ebril directly).
- **scope** — where we are allowed to use it (app shell only / marketing / App Store screenshots / all).
- **expiry** — if the license has a term, the date it expires; "perpetual" otherwise.

Don't commit files without filling a row. Anything unlicensed gets removed.

| file | photographer | rights holder | scope | expiry |
| ---- | ------------ | ------------- | ----- | ------ |
| _(example)_ press-01.jpg | Jane Doe | Universal Music Canada | app shell + App Store | perpetual |

When the team drops licensed files in, update this table in the same commit.
